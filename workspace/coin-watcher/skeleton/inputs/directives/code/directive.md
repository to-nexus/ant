# Code Directive

이것은 완성된 코드에 대한 추가 수정 요구사항이다.

개발된 코인 리스트에서 BSC network 의 CROSS라는 토큰 (컨트랙트 주소는  0x6bf62ca91e397b5a7d1d6bce97d9092065d7a510) 이것이 리스트에 추가된것이 맞는지 확인하고, 리스트 제일 앞에 나오도록 헤라. 그리고 실시간 가격 조회는 rate limit으로 제한이 걸렸기에 최신이 아니어도 좋으니 믿을수있는 가격정보(예: 전날의 종가 등)로 현재시세를 표현하도록 바꿔라. 즉 웹소켓을 이용한 실시간 연결은 제거하도록 리팩토링하라.
