## Executive Summary

ANT UI is a web-based monitoring and control interface for the ANT CLI agent system. It provides real-time visualization of LangGraph workflows, interactive task execution, and comprehensive monitoring of the AI-driven code generation process.

**Key Design Principles**:
1. **Desktop-First**: Fixed layout optimized for 1920x1080+ screens (no mobile support)
2. **Feature-Sliced Design**: Organized by business features for scalability
3. **Clean Architecture**: Clear separation of concerns with unidirectional dependencies
4. **Real-Time First**: WebSocket-based updates and file watching
5. **Type Safety**: TypeScript strict mode with @ant/cli type integration
6. **Performance**: Optimistic updates, virtual scrolling, smart memoization

## Architecture Overview

### Architectural Pattern: Feature-Sliced Design + Clean Architecture

We adopt **Feature-Sliced Design (FSD)** as the primary structural pattern, combined with **Clean Architecture** principles for dependency management.

#### Why FSD + Clean Architecture?

1. **FSD Benefits**:
   - Features are isolated and independently developable
   - Clear boundaries prevent unintended dependencies
   - Easy to scale team and codebase
   - Standard structure familiar to modern React developers

2. **Clean Architecture Benefits**:
   - Business logic independent of frameworks
   - Testable without UI or external dependencies
   - Clear dependency direction (inward only)
   - Easy to swap infrastructure (file watching → API, etc.)

3. **Why Not Hexagonal Architecture?**:
   - Hexagonal is overkill for UI applications
   - Port/Adapter pattern adds unnecessary complexity
   - FSD provides sufficient modularity
   - Focus should be on UI composition, not infrastructure abstraction

### Dependency Rule

```
Presentation → Application → Domain → Infrastructure
      ↓              ↓           ↓
   [UI]        [Use Cases]  [Entities]
```

- **Domain** has no dependencies (pure business logic)
- **Application** depends only on Domain
- **Presentation** depends on Application and Domain
- **Infrastructure** depends on Domain (implements interfaces defined in Domain)

## UI Layout Strategy

### Desktop-Only Application

**Target Platform**: Desktop browsers (Chrome, Firefox, Safari, Edge)  
**Minimum Screen Resolution**: 1920x1080 (Full HD)  
**Recommended Resolution**: 2560x1440 or higher

**Design Philosophy**:
- **Fixed Layout**: No responsive breakpoints, no media queries
- **Grid System**: CSS Grid for main layout (sidebar, content, right panel)
- **Resizable Panels**: User can resize terminal height via drag handle
- **No Touch Support**: Mouse-first interactions (hover states, context menus)
- **Rich Interactions**: Drag-drop, multi-select, keyboard shortcuts

### Why No Mobile Support?

1. **Complex Multi-Panel Layout**
   - 3-column layout requires minimum 1400px width
   - Terminal output needs horizontal space for log lines
   - Workflow graph needs space for node visualization

2. **Developer Tool**
   - Primary users are developers working on desktop
   - Code generation monitoring requires full screen
   - Multi-tasking with IDE, terminal, and ANT UI simultaneously

3. **Interaction Patterns**
   - Drag-drop for file upload
   - Context menus (right-click)
   - Keyboard shortcuts for power users
   - Hover states for additional information
   - No touch-friendly tap targets needed

4. **Performance**
   - Virtual scrolling for thousands of log lines
   - Real-time workflow graph updates
   - Multiple WebSocket connections
   - Better suited for desktop browsers

### WebSocket Integration

```typescript
// shared/api/websocket.ts
class WebSocketClient {
  private ws: WebSocket | null = null;
  private reconnectAttempts = 0;
  private maxReconnectAttempts = 5;
  private listeners = new Map<string, Set<(data: any) => void>>();
  
  connect(url: string) {
    this.ws = new WebSocket(url);
    
    this.ws.onopen = () => {
      console.log('WebSocket connected');
      this.reconnectAttempts = 0;
    };
    
    this.ws.onmessage = (event) => {
      const message = JSON.parse(event.data);
      this.notifyListeners(message.type, message.data);
    };
    
    this.ws.onclose = () => {
      console.log('WebSocket closed');
      this.attemptReconnect();
    };
    
    this.ws.onerror = (error) => {
      console.error('WebSocket error:', error);
    };
  }
  
  subscribe(eventType: string, callback: (data: any) => void) {
    if (!this.listeners.has(eventType)) {
      this.listeners.set(eventType, new Set());
    }
    this.listeners.get(eventType)!.add(callback);
    
    return () => {
      this.listeners.get(eventType)?.delete(callback);
    };
  }
  
  send(type: string, data: any) {
    if (this.ws?.readyState === WebSocket.OPEN) {
      this.ws.send(JSON.stringify({ type, data }));
    }
  }
  
  private notifyListeners(type: string, data: any) {
    const callbacks = this.listeners.get(type);
    if (callbacks) {
      callbacks.forEach(cb => cb(data));
    }
  }
  
  private attemptReconnect() {
    if (this.reconnectAttempts < this.maxReconnectAttempts) {
      const delay = Math.min(1000 * Math.pow(2, this.reconnectAttempts), 10000);
      setTimeout(() => {
        this.reconnectAttempts++;
        this.connect(this.ws!.url);
      }, delay);
    }
  }
}

export const wsClient = new WebSocketClient();
```

```typescript
export const useSessionUpdates = (project: string, feature: string) => {
```

### Key Services

#### 1. CommandService (Application Layer)

```typescript
// application/services/CommandService.ts
export class CommandService {
  constructor(
    private commandExecutor: ICommandExecutor,
    private fileWatcher: FileWatchService,
    private wsService: WebSocketService
  ) {}
  
  async executeTask(
    type: 'design' | 'code' | 'learn',
    project: string,
    feature: string
  ): Promise<Command> {
    const command: Command = {
      id: generateId(),
      type,
      project,
      feature,
      status: 'running',
      startedAt: new Date(),
    };
    
    // Start watching session and logs
    this.fileWatcher.watchSession(project, feature, (session) => {
      this.wsService.broadcast('session_update', { project, feature, session });
    });
    
    this.fileWatcher.watchLogs(project, feature, (logLines) => {
      logLines.forEach(log => {
        this.wsService.broadcast('log_line', log);
      });
    });
    
    // Execute command
    try {
      const result = await this.commandExecutor.execute(
        type,
        `workspace/${project}/${feature}/`,
        {
          onOutput: (line) => {
            const log = parseLogLine(line);
            this.wsService.broadcast('log_line', log);
          }
        }
      );
      
      command.status = 'completed';
      command.exitCode = result.exitCode;
      command.completedAt = new Date();
    } catch (error) {
      command.status = 'failed';
      command.exitCode = 1;
      command.completedAt = new Date();
    } finally {
      this.fileWatcher.stopWatching(project, feature);
    }
    
    this.wsService.broadcast('command_complete', command);
    return command;
  }
  
  cancelTask(commandId: string): void {
    this.commandExecutor.kill(commandId);
  }
}
```

```typescript
export class FileWatchService {
  private watchers = new Map<string, FSWatcher>();
  
  constructor(
    private workspacePath: string,

  watchSession(
    project: string,

      this.workspacePath,

      ignoreInitial: false,
      awaitWriteFinish: {
        stabilityThreshold: 100,
        pollInterval: 50
      }
    });
    
    watcher.on('change', async () => {
      try {
        const content = await this.fileReader.readFile(sessionPath);
        const session = SessionParser.parse(content);
        callback(session);
      } catch (error) {
        console.error('Failed to read session:', error);
      }
    });
    
    this.watchers.set(`${project}:${feature}:session`, watcher);
  }
  
  watchLogs(
    project: string,
    feature: string,
    callback: (logs: LogLine[]) => void
  ): void {
    const logsDir = path.join(
      this.workspacePath,
      project,
      feature,
      'outputs',
      'reports'
    );
    
    let lastSize = 0;
    
    const watcher = chokidar.watch(`${logsDir}/*.log`, {
      persistent: true,
      ignoreInitial: false
    });
    
    watcher.on('change', async (filePath) => {
      try {
        const stats = await fs.stat(filePath);
        
        if (stats.size > lastSize) {
          const stream = fs.createReadStream(filePath, {
            start: lastSize,
            encoding: 'utf-8'
          });
          
          const lines: string[] = [];
          const rl = readline.createInterface({ input: stream });
          
          rl.on('line', (line) => {
            if (line.trim()) {
              lines.push(line);
            }
          });
          
          rl.on('close', () => {
            const logs = lines.map(LogParser.parse);
            callback(logs);
          });
          
          lastSize = stats.size;
        }
      } catch (error) {
        console.error('Failed to read log:', error);
      }
    });
    
    this.watchers.set(`${project}:${feature}:logs`, watcher);
  }
  
  stopWatching(project: string, feature: string): void {
    const sessionKey = `${project}:${feature}:session`;
    const logsKey = `${project}:${feature}:logs`;
    
    this.watchers.get(sessionKey)?.close();
    this.watchers.get(logsKey)?.close();
    
    this.watchers.delete(sessionKey);
    this.watchers.delete(logsKey);
  }
}
```

#### 3. WebSocketService (Application Layer)

```typescript
// application/services/WebSocketService.ts
export class WebSocketService {
  private wss: WebSocketServer;
  private clients = new Map<WebSocket, Set<string>>(); // client → subscribed topics
  
  constructor(server: Server) {
    this.wss = new WebSocketServer({ server });
    
    this.wss.on('connection', (ws) => {
      console.log('Client connected');
      this.clients.set(ws, new Set());
      
      ws.on('message', (data) => {
        try {
          const message = JSON.parse(data.toString());
          this.handleMessage(ws, message);
        } catch (error) {
          console.error('Invalid message:', error);
        }
      });
      
      ws.on('close', () => {
        console.log('Client disconnected');
        this.clients.delete(ws);
      });
    });
  }
  
  private handleMessage(ws: WebSocket, message: any) {
    const { type, data } = message;
    
    switch (type) {
      case 'subscribe':
        const topic = `${data.project}:${data.feature}`;
        this.clients.get(ws)?.add(topic);
        break;
        
      case 'unsubscribe':
        const unsubTopic = `${data.project}:${data.feature}`;
        this.clients.get(ws)?.delete(unsubTopic);
        break;
    }
  }
  
  broadcast(type: string, data: any) {
    const message = JSON.stringify({ type, data });
    
    // Check if this is a targeted message (has project/feature)
    const topic = data.project && data.feature 
      ? `${data.project}:${data.feature}`
      : null;
    
    this.clients.forEach((topics, client) => {
      if (client.readyState === WebSocket.OPEN) {
        // Send to all if no topic, or only to subscribed clients
        if (!topic || topics.has(topic)) {
          client.send(message);
        }
      }
    });
  }
}
```

```typescript
          <DialogTitle>Task Paused</DialogTitle>
          <DialogDescription>
            Execution paused due to recursion limit.
          </DialogDescription>
        </DialogHeader>
        
        <div className="space-y-2">
          <p>
            <span className="font-semibold">{tasksCompleted}</span> tasks completed
          </p>
          <p>
            <span className="font-semibold">{tasksRemaining}</span> tasks remaining
          </p>
        </div>
        
        <p className="text-sm text-muted-foreground">
          Would you like to resume from the last checkpoint?
        </p>
        
        <DialogFooter>
          <Button variant="outline" onClick={onAbort}>
            Abort
          </Button>
          <Button onClick={onResume}>
            Resume
          </Button>
        </DialogFooter>
      </DialogContent>
    </Dialog>
  );
};
```

### Error Boundary

```typescript
// app/ErrorBoundary.tsx
export class ErrorBoundary extends React.Component<Props, State> {
  constructor(props: Props) {
    super(props);
    this.state = { hasError: false, error: null };
  }
  
  static getDerivedStateFromError(error: Error) {
    return { hasError: true, error };
  }
  
  componentDidCatch(error: Error, errorInfo: ErrorInfo) {
    console.error('ErrorBoundary caught:', error, errorInfo);
  }
  
  render() {
    if (this.state.hasError) {
      return (
        <div className="flex items-center justify-center h-screen">
          <Card>
            <CardHeader>
              <CardTitle>Something went wrong</CardTitle>
            </CardHeader>
            <CardContent>
              <p className="text-sm text-muted-foreground">
                {this.state.error?.message}
              </p>
            </CardContent>
            <CardFooter>
              <Button onClick={() => window.location.reload()}>
                Reload Application
              </Button>
            </CardFooter>
          </Card>
        </div>
      );
    }
    
    return this.props.children;
  }
}
```
