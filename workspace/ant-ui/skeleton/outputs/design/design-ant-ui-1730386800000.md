## Executive Summary

**간단한 데스크톱 앱**으로 ANT CLI 실행 상태를 모니터링합니다.

**핵심 제약사항**:
- ANT CLI는 API를 제공하지 않음
- `session.json` 파일만 읽어서 상태 파악
- `child_process`로 CLI 실행
- `chokidar`로 파일 변화 감지

**이게 전부입니다. 웹소켓도, REST API도, 복잡한 아키텍처도 필요 없습니다.**

```typescript
// lib/projects.ts
export async function listProjects(): Promise<string[]> {
  const workspaceDir = path.join(process.cwd(), '../../workspace');
  const entries = await fs.readdir(workspaceDir, { withFileTypes: true });
  return entries.filter(e => e.isDirectory()).map(e => e.name);
}
```

```typescript
export function executeCodeTask(project: string): ChildProcess {
  const proc = spawn('pnpm', [
    'dev', 
    'arch', 
    'code', 
    `../../workspace/${project}/skeleton/outputs/design/*.md`
  ], {
    cwd: path.join(process.cwd(), '../ant-cli'),
    shell: true
  });

    store.getState().addLog(data.toString());
  });
  
  return proc;
}
```

### 3. 세션 상태 표시 (SessionView.tsx)

**기능**:
- `session.json` 읽기

**구현**:
```typescript
// lib/session.ts
export async function loadSession(project: string): Promise<Session | null> {
  const sessionPath = path.join(
    process.cwd(),
    '../../workspace',
    project,
    'skeleton/outputs/session.json'
  );
  
  try {
    const content = await fs.readFile(sessionPath, 'utf-8');
    return JSON.parse(content);
  } catch {
    return null;
  }
}

export function watchSession(
  project: string, 
  callback: (session: Session) => void
): FSWatcher {
  const sessionPath = path.join(
    process.cwd(),
    '../../workspace',
    project,
    'skeleton/outputs/session.json'
  );
  
  const watcher = chokidar.watch(sessionPath, {
    ignoreInitial: false,
    awaitWriteFinish: { stabilityThreshold: 100 }
  });
  
  watcher.on('change', async () => {
    const session = await loadSession(project);
    if (session) callback(session);
  });
  
  return watcher;
}
```

## Main App Component

```typescript
// App.tsx
export function App() {
  const { 
    selectedProject, 
    session, 
    isRunning,
    selectProject, 
    setSession, 
    setRunning 
  } = useStore();
  
  const [projects, setProjects] = useState<string[]>([]);
  
  // Load projects on mount
  useEffect(() => {
    listProjects().then(setProjects);
  }, []);
  
  // Watch session when project selected
  useEffect(() => {
    if (!selectedProject) return;
    
    const watcher = watchSession(selectedProject, setSession);
    loadSession(selectedProject).then(s => s && setSession(s));
    
    return () => watcher.close();
  }, [selectedProject]);
  
  const handleRunCode = () => {
    if (!selectedProject || isRunning) return;
    
    setRunning(true);
    const proc = executeCodeTask(selectedProject);
    
    proc.on('exit', () => setRunning(false));
  };
  
  return (
    <div className="h-screen flex flex-col">
      <Header 
        onRunCode={handleRunCode} 
        isRunning={isRunning}
      />
      
      <div className="flex-1 flex">
        {/* Left: Projects */}
        <aside className="w-64 border-r p-4">
          <ProjectList 
            projects={projects}
            selected={selectedProject}
            onSelect={selectProject}
          />
        </aside>
        
        {/* Center: Session + Tasks */}
        <main className="flex-1 p-4 space-y-4">
          <SessionView session={session} />
          <TaskQueue session={session} />
        </main>
      </div>
      
      {/* Bottom: Terminal */}
      <footer className="border-t">
        <TerminalOutput />
      </footer>
    </div>
  );
}
```

## Non-Functional Requirements

### Performance

- `session.json` 파일 크기 < 1MB (괜찮음)
- 업데이트 지연 < 200ms (chokidar stabilityThreshold)
- 터미널 로그 최대 500줄 (메모리 절약)

### Reliability

- `session.json` 파싱 실패시 에러 무시 (다음 업데이트 대기)
- CLI 프로세스 크래시시 UI는 계속 작동
- 파일 watcher 끊기면 재연결 (chokidar 자동 처리)
