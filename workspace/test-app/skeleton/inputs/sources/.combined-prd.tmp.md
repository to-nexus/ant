# 프로젝트: Simple Tasks
## 목적
간단한 할 일 관리 웹 애플리케이션을 만든다.

## 주요 기능
- 사용자는 새로운 할 일을 입력할 수 있다.
- 각 할 일은 완료 상태를 가질 수 있다.
- 사용자는 할 일을 완료하거나 미완료로 전환할 수 있다.
- 사용자는 할 일을 삭제할 수 있다.
- 사용자는 전체 / 완료 / 미완료 필터를 통해 목록을 볼 수 있다.

## 기술 제약
- React + Vite + TypeScript
- 외부 API 불필요
- 상태는 useState로 관리
- 디자인은 최소한으로 (Tailwind OK)

## 성공 기준
- npm run dev 로 실행 가능한 상태일 것
- 모든 주요 기능이 동작할 것
- ellipsis 없이 완전한 코드 생성
