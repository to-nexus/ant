# ANT를 통한 Prediction Market 개발 일정 관련

---

## 프로젝트 범위와 ANT의 커버리지

이번 Prediction Market은 Polymarket을 벤치마크한 서비스로, 프론트엔드 1개, 백엔드 4~5개(API 서버, 실시간 매칭 엔진, 과금, 오라클 등), 어드민 프론트/백엔드를 포함하는 **6개 이상의 서비스로 구성된 중대형 프로젝트**입니다.

ANT는 이 중 프론트엔드만 생성하는 것이 아니라, **모든 백엔드 서비스와 인프라(DB, Redis 등)까지 포함한 전체 스택을 산출물로 생성**하는 것이 목표입니다. 또한 당사 개발팀의 요구에 따라 TypeScript뿐 아니라 **Go 언어까지 지원 범위에 포함**하여 진행 중입니다.

이 수준의 커버리지를 제공하는 AI 코딩 도구는 현재 시장에 거의 없습니다. 대부분의 도구(v0, Bolt.new, Lovable)는 프론트엔드 전용이고, Replit Agent이나 Devin도 복수 서비스 간 연동 및 인프라 오케스트레이션은 지원하지 않습니다. (상세 비교표 별첨)

## 현재 진행 상태

현재 ANT 시스템 측면에서는 Go 언어 지원, 멀티 서비스 인프라 연동(서비스 간 커넥션 자동 감지, DB/Redis 연결), 프롬프트 파이프라인 안정화 작업을 진행 중이며 구현은 상당 부분 완료되어 **테스트와 결함 수정 단계**에 있습니다. 이 작업을 1인이 전담하고 있는 상황입니다.

프로젝트 측면에서는 **기획 확정이 금주~차주, 디자인 시스템이 적용된 피그마 디자인 역시 차주까지 진행 예정**으로, 이 기간 동안 ANT의 시스템 안정화를 병행합니다. 차차주부터 ANT로 실제 Prediction Market을 생성하고, 각 파트 담당자(프론트엔드, 백엔드 API, 매칭 엔진, 과금, 오라클, 어드민)가 산출물을 확인한 뒤 보완하는 프로세스를 시작할 예정입니다.

## 기대 효과와 일정 전망

ANT 산출물의 품질이 각 담당자가 바로 이어받아 작업할 수 있는 수준으로 확인되면, **3월 25일보다 앞당겨질 가능성이 충분히 있습니다.** 핵심은 초기 산출물의 완성도이며, 이를 위해 현재 시스템 안정화에 집중하고 있습니다.

이번 Prediction Market은 ANT의 첫 실전 프로젝트이기도 합니다. **프론트엔드, 백엔드, 인프라를 아우르는 프로덕션 수준의 풀스택 코드를 AI가 생성하고 실제 서비스에 적용하는 것이 검증되면, 이후 모든 프로젝트에 동일한 생산성 향상을 적용할 수 있는 기반이 됩니다.** 3월 25일이라 하더라도 그 검증이 완료되는 시점이며, 그 이후부터는 개선의 영역입니다.

### Tier 2: Full-Stack 가능 (제한적)

| 제품 | 설명 | Backend 언어 | Multi-Service | DB/인프라 |
|------|------|-------------|---------------|-----------|
| **Replit Agent** | 클라우드 IDE 내 자율 에이전트 | JS, Python | 단일 앱 기준 | Neon PostgreSQL (플랫폼 내장) |
| **Devin** (Cognition) | 자율 AI 소프트웨어 엔지니어 | Python(FastAPI) 기본, 타 언어 가능 | 지원 없음 | 외부 설정 필요 |
| **Cursor** | VS Code 기반 AI 코딩 어시스턴트 | 언어 무관 (어시스트) | 지원 없음 | 지원 없음 |

- Replit: 자체 생태계 내에서는 강력하나, 외부 배포·커스텀 인프라 구성에 제약
- Devin: 범용성은 높으나 복수 서비스 오케스트레이션, 인프라 자동 구성 미지원
- Cursor: 코드 어시스트 도구로, 프로젝트 생성·인프라 구성은 범위 밖

### Tier 3: Full-Stack + Infra + Polyglot (ANT 목표 영역)

| 항목 | ANT |
|------|-----|
| **Frontend** | React, Next.js (SSR), Vue, Svelte 등 |
| **Backend** | TypeScript (Express, NestJS, Fastify), **Go (gin)** |

| **Polyglot** | 언어/프레임워크 분리 설계로 Go, TS 동시 지원 |

## 핵심 차별점 요약

### 1. 커스텀 백엔드 비즈니스 로직 생성

대부분의 도구는 백엔드를 Supabase, Firebase 같은 BaaS에 위임합니다. ANT는 **비즈니스 로직이 포함된 실제 백엔드 코드를 생성**합니다. 매칭 엔진, 과금 로직, 오라클 연동 같은 도메인 로직을 포함한 서버를 만들 수 있는 AI 도구는 Devin 외에는 거의 없으며, Devin도 복수 서비스를 하나의 프로젝트로 오케스트레이션하는 기능은 없습니다.

### 2. 인프라 구성이 산출물에 포함

다른 도구들은 "코드만 생성"하고 인프라는 사용자 몫입니다. ANT는 docker-compose.yml 생성, 서비스 간 환경변수 자동 주입, DB/Redis 연결 설정까지 산출물에 포함시킵니다.

### 3. Polyglot (Go + TypeScript)

Go를 first-class로 지원하는 AI 코딩 에이전트는 현재 확인되지 않습니다. Devin은 Go 프로젝트를 다룰 수 있으나 템플릿 기반이 아닌 범용 대응이며, Replit Agent은 Go를 지원하지 않습니다. ANT는 언어와 프레임워크를 분리한 아키텍처로 설계되어 Go(gin)와 TypeScript(Express/NestJS)를 체계적으로 지원합니다.

### 4. End-to-End 파이프라인

| 단계 | ANT | Devin | Replit | Bolt/Lovable |
|------|-----|-------|--------|-------------|
| PRD → System Design | O | X | X | X |
| System Design → UI Design | O | X | X | X |
| Design → Code 생성 | O | O (코드만) | O (코드만) | O (FE만) |
| Runtime 검증 (빌드/린트) | O | O | O | 제한적 |
| Multi-Service Preview | O | X | X | X |
| 학습/개선 루프 | O | 부분적 | 부분적 | X |

ANT는 기획 문서(PRD)부터 시스템 설계, UI 설계, 코드 생성, 빌드 검증, 학습까지 **6단계 파이프라인**을 일관되게 실행합니다. 이 전체 흐름을 자동화한 도구는 현재 시장에 없습니다.
