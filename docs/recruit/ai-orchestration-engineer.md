# AI Orchestration Engineer (LangGraph & Prompt)

---

### Project Introduction
ANT Works is an AI-native agent framework that programs and ships software via LangGraph-based workflows, prompt engines, and autonomous workspaces.

### Role Overview
Lead the LangGraph orchestration layer, prompt engine policies, and tool-calling safeguards so that multi-agent jobs run deterministically with measurable quality.

### Reporting & Collaboration
- **Direct Report:** Chief Architect who designed and built the initial architecture
- **Working Relationship:** Work closely with the founding architect on architecture decisions, design reviews, and sprint planning while maintaining hands-on ownership of the orchestration domain
- **Peer Collaboration:** Partner with the AI Systems Engineer on data contracts, context schemas, and end-to-end workflow validation

### Key Responsibilities

**1. Workflow Architecture**
- Refine existing LangGraph nodes (detect, plan, execute, review) with explicit I/O schemas, retry/rollback logic, and mode inference.

**2. Prompt & Policy Engine**
- Consolidate prompt templates, guardrails, and policy enforcement paths in PromptEngine, reducing token cost while preserving coverage.

**3. Tooling & Simulation**
- Build mock LLM/test harnesses, prompt diff visualizers, and workflow debuggers to reproduce edge cases quickly.

**4. Cross-Team Interfaces**
- Collaborate with Chief Architect on architectural decisions, API design patterns, and quality gates for production readiness.
- Define contracts with the systems engineer for context payloads, memory hooks, and telemetry surfaces.

### Minimum Qualifications
- 5+ years building backend workflows or automation engines with strong TypeScript/Node.js fundamentals.
- Hands-on with LangChain/LangGraph, multi-step prompt orchestration, or agent tool-calling pipelines.
- Ability to design evaluation loops (self-check, auto-review, regression suites) for LLM tasks.

### Nice to Have
- Exposure to Anthropic/OpenAI APIs, SSE streaming UX, or policy/guardrail systems.

### Success Indicators
- Deterministic LangGraph runs with clear observability, prompt cost metrics trending down, and reduced retry/error rates.

### 프로젝트 소개
ANT Works는 LangGraph 워크플로, 프롬프트 엔진, 자율 워크스페이스를 통해 소프트웨어 개발을 자동화하는 AI 네이티브 에이전트 프레임워크입니다.

### 역할 개요
LangGraph 오케스트레이션 계층과 프롬프트 엔진 정책, 툴 콜링 안전장치를 주도하여 멀티 에이전트 작업이 측정 가능한 품질로 안정 실행되도록 합니다.

### 보고 및 협업 체계
- **직속 보고:** Chief Architect에게 직접 보고
- **업무 관계:** 창립 아키텍트와 긴밀히 협업하며 아키텍처 의사결정, 설계 리뷰, 스프린트 계획을 함께 수행하되, 오케스트레이션 영역의 실질적 오너십을 보유
- **동료 협업:** AI Systems Engineer와 데이터 계약, 컨텍스트 스키마, 엔드투엔드 워크플로 검증을 협업

### 주요 업무

**1. 워크플로 아키텍처**
- LangGraph 노드(감지·계획·실행·리뷰)의 입출력 스키마, 재시도/롤백 로직, 모드 추론을 명시화하고 개선합니다.

**2. 프롬프트 & 정책 엔진**
- PromptEngine 내 템플릿·가드레일·정책 집행 경로를 통합해 토큰 비용을 줄이면서 커버리지를 유지합니다.

**3. 툴링 & 시뮬레이션**
- 모의 LLM·테스트 하네스·프롬프트 diff 시각화·워크플로 디버거를 구축하여 엣지 케이스를 빠르게 재현합니다.

**4. 크로스팀 인터페이스**
- Chief Architect와 아키텍처 의사결정, API 설계 패턴, 프로덕션 준비도 품질 게이트를 협의합니다.
- 컨텍스트 페이로드·메모리 훅·텔레메트리 표준을 시스템 엔지니어와 합의합니다.

### 자격 요건
- 백엔드 워크플로·자동화 엔진 5년 이상 경험, TypeScript/Node.js 기반 탄탄한 역량.
- LangChain/LangGraph, 멀티스텝 프롬프트 오케스트레이션, 에이전트 툴 콜링 파이프라인 실무 경험.
- LLM 작업용 셀프 체크·오토 리뷰·회귀 스위트를 설계한 경험.

### 우대 사항
- Anthropic/OpenAI API, SSE 스트리밍 UX, 정책/가드레일 시스템 경험.

### 기대 성과
- 가시성이 확보된 결정적 LangGraph 실행, 하향 안정화된 프롬프트 비용, 감소한 재시도·에러 비율.
