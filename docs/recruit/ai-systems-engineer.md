# AI Systems Engineer (Vector & Chunking)

---

### Project Introduction
ANT Works is an AI-native agent framework that pipelines coding and software development end-to-end, combining LangGraph-driven orchestration with vectorized memory and workspace automation.

### Role Overview
Own the chunking, indexing, and retrieval stack inside `ant-cli`, hardening the data path that feeds every agent while instrumenting quality metrics and regression tests.

### Reporting & Collaboration
- **Direct Report:** Chief Architect who designed and built the initial architecture
- **Working Relationship:** Collaborate with the founding architect on system design, performance optimization strategies, and infrastructure roadmap while driving day-to-day execution of the data pipeline
- **Peer Collaboration:** Work with the AI Orchestration Engineer to align on context delivery contracts and observability standards

### Key Responsibilities

**1. Pipeline Ownership**
- Audit and refactor ChunkEngine, loaders/splitters/cleaners, and CodebaseIndexer strategies for different file types.

**2. Vector Memory & Retrieval**
- Design multi-collection storage policies, adaptive chunk sizing, and retrieval/rerank evaluation flows on Chroma or equivalent vector DBs.

**3. Observability & QA**
- Build automated metrics (hit rate, token cost, drift) and regression harnesses using representative workspaces and mock LLMs.

**4. Collaboration**
- Report to Chief Architect on data pipeline health, performance bottlenecks, and scalability proposals with measurable impact analysis.
- Partner with the orchestration engineer to define context schemas and surface actionable telemetry to LangGraph nodes.

### Minimum Qualifications
- 5+ years in backend or data infrastructure with hands-on experience in text chunking, vector databases, or large-scale search systems.
- Proficiency in TypeScript/Node.js and familiarity with AST/graph analysis tooling.
- Comfortable designing metrics dashboards or offline evaluation loops for ML/RAG workflows.

### Nice to Have
- Experience with ChromaDB, LanceDB, or Milvus; LangChain/LangGraph integration; Git-aware indexing.

### Success Indicators
- Stable chunk/retrieval metrics with automated alerts, reproducible data fixtures, and documented best practices.

### 프로젝트 소개
ANT Works는 LangGraph 기반 오케스트레이션과 벡터 메모리, 워크스페이스 자동화를 결합하여 코딩과 개발을 파이프라인화하는 AI 네이티브 에이전트 프레임워크입니다.

### 역할 개요
`ant-cli` 내부의 청킹·인덱싱·리트리벌 스택을 책임지고, 모든 에이전트의 데이터를 공급하는 경로를 고도화하며 품질 지표와 회귀 테스트를 구축합니다.

### 보고 및 협업 체계
- **직속 보고:** Chief Architect에게 직접 보고
- **업무 관계:** 창립 아키텍트와 시스템 설계, 성능 최적화 전략, 인프라 로드맵을 협의하며 데이터 파이프라인의 일상적 실행을 주도
- **동료 협업:** AI Orchestration Engineer와 컨텍스트 전달 계약 및 관찰성 표준을 정렬

### 주요 업무

**1. 파이프라인 오너십**
- ChunkEngine 및 각 로더/스플리터/클리너, CodebaseIndexer 전략을 감사·리팩터링하여 파일 타입별 최적화를 수행합니다.

**2. 벡터 메모리 & 리트리벌**
- Chroma 등 벡터 DB에서 멀티 컬렉션 정책, 적응형 청크 크기, 리트리벌·재랭킹 평가 플로우를 설계합니다.

**3. 관찰성 & QA**
- 대표 워크스페이스와 모의 LLM을 활용하여 히트율·토큰 비용·드리프트 등의 자동화 지표와 회귀 하네스를 구축합니다.

**4. 협업**
- Chief Architect에게 데이터 파이프라인 상태, 성능 병목, 확장성 제안을 측정 가능한 영향 분석과 함께 보고합니다.
- 오케스트레이션 엔지니어와 협업하여 컨텍스트 스키마를 정의하고 LangGraph 노드가 바로 활용할 수 있는 텔레메트리를 제공합니다.

### 자격 요건
- 백엔드 또는 데이터 인프라 5년 이상 경력, 텍스트 청킹·벡터 DB·대규모 검색 시스템 실무 경험 필수.
- TypeScript/Node.js 숙련 및 AST·그래프 분석 도구 경험.
- ML/RAG 워크플로를 위한 지표 대시보드·오프라인 평가 루프 설계 경험.

### 우대 사항
- ChromaDB, LanceDB, Milvus 사용 경험, LangChain/LangGraph 연동 경험, Git 연동형 인덱싱 경험.

### 기대 성과
- 자동 경보가 달린 안정적 청크/리트리벌 지표, 재현 가능한 데이터 픽스처, 정리된 모범 사례 문서화.
