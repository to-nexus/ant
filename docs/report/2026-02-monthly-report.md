# ANT 프로젝트 월간보고 — 2026년 2월

> **보고 기간**: 2026.02.01 ~ 2026.02.27  
> **작성일**: 2026.02.27

---

## 1. Executive Summary

**ANT(AI-Native Transformation)** 는 PRD 작성부터 시스템 설계, 코드 생성, 테스트, 프리뷰까지를 AI 에이전트가 자동 수행하는 소프트웨어 개발 플랫폼입니다.

2월에는 **클라우드 분산 시스템 전환을 완료**하고, **멀티에이전트 아키텍처**와 **병렬 코드 생성** 체계를 구축했습니다. 이를 통해 ANT는 개인 PC용 프로토타입에서 **기업 팀 단위로 동시 사용 가능한 클라우드 서비스**로 전환되었습니다.

## 2. 2월 핵심 성과

### 2.1 클라우드 분산 시스템 전환 완료

| 항목 | 내용 |
|------|------|
| **기간** | 2월 1주 ~ 2주 |
| **핵심 변경** | 전체 상태 관리(Chat, Kanban, Workflow)를 Redis 기반으로 전환 |
| **인프라** | AWS ElastiCache(Redis TLS), EFS, Kubernetes 인그레스 구성 |
| **Realtime 서버** | 독립 프로세스로 분리, SSE 멀티탭/멀티파드 동기화 |

**이것이 왜 중요한가:**  
기존에는 단일 개발 머신에서만 동작하던 시스템이, 이제 **AWS 클라우드에서 다수의 사용자가 동시에 접속하여 사용할 수 있는 구조**로 전환되었습니다. 서비스화의 기술적 기반이 완성된 것입니다.

### 2.2 멀티에이전트 아키텍처 도입

2월 이전에는 "코드 생성 에이전트" 하나가 모든 작업을 처리했습니다. 2월에 **역할별 전문 에이전트** 체계로 전환했습니다.

| 에이전트 | 역할 | 2월 신규 |
|----------|------|---------|
| **Planner** | PRD 작성, 요구사항 정제, 명확화 질문 | **신규** |
| **Architect (Design)** | 시스템 설계, UI 설계 문서 생성 | 기존 |
| **Architect (Code)** | 소스 코드 생성, 테스트, 검증 | 기존 |
| **Architect (Ask)** | 코드베이스 기반 질의응답 | 기존 |
| **Triage** | 사용자 의도 분류 → 적합 에이전트 자동 라우팅 | **신규** |

**작동 방식:**  
사용자가 채팅으로 요청하면, Triage 시스템이 의도를 분석하여 기획/설계/코드/질문 중 어떤 에이전트가 처리할지 자동 판단합니다. 에이전트가 작업 중 추가 정보가 필요하면 사용자에게 **역질문(Inline-ask)** 도 가능합니다.

**이것이 왜 중요한가:**  
"코드만 짜는 도구"에서 **"기획부터 코드까지 전 과정을 커버하는 AI 개발팀"** 으로 제품 성격이 격상되었습니다.

### 2.3 병렬 코드 생성 및 품질 자동화

| 기능 | 설명 |
|------|------|
| **병렬 태스크 실행** | 여러 워커가 동시에 다른 파일/모듈을 코드 생성 |
| **파일 충돌 해결** | 병렬 워커 간 같은 파일 수정 시 자동 머지 (Session File Manifest) |
| **Verification** | 코드 생성 완료 후 자동으로 통합 검증 태스크 실행 |
| **TestGen** | 백엔드 코드에 대한 테스트 코드 자동 생성 |
| **보안 원칙 내장** | 보안 코딩 원칙, .env 보호 규칙이 프롬프트에 내장 |

**이것이 왜 중요한가:**  
대부분의 AI 코딩 도구가 파일을 하나씩 순차적으로 생성하는 반면, ANT는 **여러 파일을 동시에 생성**합니다. 대규모 프로젝트에서 속도 우위가 생기며, **자동 검증과 테스트 생성**을 통해 "만들기만 하고 안 돌아가는" 문제를 방지합니다.

### 2.4 프리뷰 시스템 고도화

| 기능 | 설명 |
|------|------|
| **독립 서비스 분리** | ant-preview를 별도 프로세스로 독립 (기존 API 서버 내장 → 분리) |
| **SSR 지원** | Next.js Server-Side Rendering + basePath 프록시 |
| **HMR 프록시** | WebSocket 기반 Hot Module Replacement 지원 |
| **Go 지원** | Go 언어 toolchain 자동 감지 및 실행 |
| **멀티 서비스** | MSA 구조에서 여러 서비스(FE/BE)를 동시에 프리뷰 |

**이것이 왜 중요한가:**  
AI가 생성한 코드를 **즉시 실행하고 화면으로 확인**할 수 있습니다. "코드는 만들었는데 돌려보려면 환경 세팅을 직접 해야 하는" 문제를 해결했습니다.

### ANT가 다른 이유 — 세 가지 핵심 차별점

**1. "설계를 먼저 한다"**

대부분의 바이브코딩 도구는 사용자의 프롬프트에서 **바로 코드를 생성**합니다. 빠르지만, 프로젝트가 커지면 코드 간 정합성이 무너지고 유지보수가 어려워집니다.

ANT는 **PRD(기획서) → 시스템 설계 → UI 설계 → 코드** 순서로 진행합니다. 설계 문서가 코드 생성의 사양서 역할을 하기 때문에, 여러 모듈이 서로 맞지 않는 문제를 구조적으로 방지합니다. 실제 소프트웨어 개발 프로세스를 AI가 따르는 것입니다.

**2. "여러 파일을 동시에 만든다"**

Devin을 포함한 대부분의 도구는 하나의 에이전트가 파일을 순차적으로 생성합니다. ANT는 **여러 워커가 동시에 서로 다른 모듈의 코드를 병렬 생성**하고, 같은 파일을 수정한 경우 자동으로 충돌을 해결합니다. 대규모 프로젝트에서 생성 속도의 차이가 명확해집니다.

**3. "클라우드에서 팀이 함께 쓴다"**

Cursor/Windsurf는 개인 PC에 설치하는 에디터이고, Bolt/Lovable는 간단한 앱을 만드는 도구입니다. ANT는 **Kubernetes 기반 분산 시스템**으로, 기업 개발팀이 동시에 접속하여 각자의 프로젝트를 병렬로 진행할 수 있습니다. 엔터프라이즈 환경을 전제로 설계된 유일한 설계-주도 AI 코딩 플랫폼입니다.

## 5. 3월 방향성

### 최우선 목표: ANT로 만든 첫 상용 제품 출시

3월의 가장 큰 목표는 **ANT를 사용하여 실제 상용 서비스를 개발하고 출시**하는 것입니다.

| 항목 | 내용 |
|------|------|
| **프로젝트명** | Prediction Market |
| **기술 스택** | Go Backend (MSA) + Next.js Frontend |
| **개발 방식** | ANT 플랫폼을 사용한 풀스택 개발 |

**이것이 왜 중요한가:**

ANT가 "도구 자체를 개발하는 단계"에서 **"도구를 사용하여 실제 제품을 만드는 단계"** 로 전환됩니다. 자체 도그푸딩(dogfooding)을 통해 ANT의 실전 성능을 검증하고, 실사용에서 발견되는 문제를 즉시 개선하는 피드백 루프를 확보합니다.

2월에 집중 구축한 **Go MSA 지원, Next.js SSR 프리뷰, 병렬 코드 생성**이 바로 이 프로젝트를 위한 기반 기술이었습니다.
