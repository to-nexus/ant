Iteration loop  ·  every change after that
Design gen-spec
One unit of change, reviewed before any code runs
architecture/spec/
Code gen-code-spec
Implements exactly that one spec
codebase/

No PRD, no system design. The spec is the unit of change — the same shape as plan mode, except the plan is a file you can diff, review and revise instead of a message that scrolls away.

rev-spec

Because each stage is a file rather than a message, you can review it, argue with it, and re-run only the stage you changed — the next stage reads the corrected artifact, not a longer conversation.
