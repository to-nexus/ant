A / in a feature name is stored as ~ on disk — the directory is a projection, the branch keeps the name you gave it.

The branch name is the feature name — no prefix, no sanitising, so feature/base and release/1.0 work as you would expect. Run several features at once, each with its own checkout, preview and artifacts.
