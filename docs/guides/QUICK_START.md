# Quick Start

## Prerequisites

```bash
# Node.js 18+
node --version

# pnpm
npm install -g pnpm

# Docker (for ChromaDB)
docker --version
```

## Setup

```bash
# Clone repository
git clone <repo-url>
cd ant

# Install dependencies
pnpm install

# Environment
cat > .env << EOF
OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=sk-ant-...
CHROMA_URL=http://localhost:8000
EOF

# Start ChromaDB
cd src/periphery/integrations/vector-memory
docker-compose up -d
cd ../../../../

# Build
npm run build
```

## Common Workflows

### New Feature

```bash
# Generate design
npm run dev -- arch design workspace/myapp/feature1/

# Edit PRD
vim workspace/myapp/feature1/inputs/sources/prd.md

# Regenerate design
npm run dev -- arch design workspace/myapp/feature1/

# Generate code
npm run dev -- arch code workspace/myapp/feature1/
```

### Code Modification

```bash
# Write directive
echo "Fix button styling in Header component" > \
  workspace/myapp/feature1/inputs/directives/code/directive.md

# Generate code (uses existing design + directive)
npm run dev -- arch code workspace/myapp/feature1/
```

### With Evaluation

```bash
# Generate code with quality evaluation
npm run dev -- arch code workspace/myapp/feature1/ --eval

# Check evaluation report
cat workspace/myapp/feature1/outputs/eval/report.md
```

## Checkpointing & Recovery

### How It Works

State saved at critical points:
1. After `plan` - Task plan generated
2. After `execute` - Files generated by LLM
3. After `runtimeValidate` - Validation complete

Saved to: `workspace/project/feature/session.json`

### Resume After Interruption

```bash
# Same command resumes from checkpoint
npm run dev -- arch code workspace/myapp/feature1/
```

### Clear and Restart

```bash
# Delete session
rm workspace/myapp/feature1/session.json

# Start fresh
npm run dev -- arch code workspace/myapp/feature1/
```

## Configuration

### Workspace Config

Edit `workspace/myapp/config.json`:

```json
{
  "projectName": "myapp",
  "branchBase": "main",
  "autoLearn": true,
  "strictValidation": true,
  "runTests": false,
  "llmProvider": "anthropic",
  "llmModel": "claude-sonnet-4-5"
}
```

### LLM Models

**OpenAI**:
- `gpt-4-turbo-preview`
- `gpt-4`
- `gpt-3.5-turbo`

**Anthropic**:
- `claude-sonnet-4-5` (recommended)

## Troubleshooting

### ChromaDB not running

```bash
cd src/periphery/integrations/vector-memory
docker-compose up -d
```

### API key not found

Check `.env` file:
```bash
cat .env
```

Ensure keys are set:
```bash
OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=sk-ant-...
```

### TypeScript errors

```bash
# Type check
npx tsc --noEmit

# Rebuild
npm run build
```

### Workspace not found

Ensure path starts with `workspace/`:
```bash
# Bad
npm run dev -- arch code myapp/feature1/

# Good
npm run dev -- arch code workspace/myapp/feature1/
```
