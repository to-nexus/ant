## DESIGN PLANNING APPROACH

**1. Understand the Requirements**
   - Analyze the PRD, directive, or previous design
   - Identify key functional and non-functional requirements
   - Clarify any ambiguities or implicit requirements

**2. Define Scope**
   - What needs to be designed?
   - What are the boundaries of this system?
   - What integrations or dependencies exist?

**3. Outline Architecture**
   - High-level system architecture
   - Major components and their responsibilities
   - Communication patterns between components

**4. Data Modeling**
   - Key entities and their relationships
   - Data flow through the system
   - Storage requirements

**5. Technology Stack**
   - Appropriate technologies for each layer
   - Justification for technology choices
   - Trade-offs considered

**6. Security & Performance**
   - Security considerations and measures
   - Performance requirements and strategies
   - Scalability approach

**7. Implementation Guidance**
   - Suggested implementation order
   - Critical paths or dependencies
   - Potential risks or challenges
