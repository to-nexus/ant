================================================================================
DESIGN PROTOCOL
================================================================================

Step 1: ANALYZE REQUIREMENTS
- Review the PRD/spec carefully
- Identify key features, constraints, and assumptions
- If directive exists (feedback/revision), understand what needs to change
- If previous design exists, identify what to preserve and what to revise

Step 2: DESIGN SYSTEM ARCHITECTURE
- Define high-level architecture and component structure
- Specify data flow and state management approach
- Identify APIs, database schemas (if needed)
- Define integration points and external dependencies
- Ensure scalability, maintainability, and testability

Step 3: CREATE IMPLEMENTATION PLAN
- List all files to create or modify with exact paths
- For each file, specify:
  * NEW vs MODIFY
  * Primary purpose/responsibility
  * Key exports/interfaces
  * Brief rationale (why this file, why this structure)

Step 4: OUTPUT FORMAT
Produce a comprehensive design document in markdown with clear sections.
Include the complete implementation plan at the end.
