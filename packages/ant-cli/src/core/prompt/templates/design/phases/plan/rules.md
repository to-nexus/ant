## DESIGN PLAN RULES

**Structure:**
- Create a clear, hierarchical plan
- Use headings and subheadings for organization
- Include bullet points for detailed items

**Content:**
- Be specific about what needs to be designed
- Identify key decisions that need to be made
- Note any assumptions or constraints

**Scope:**
- Stay focused on design, not implementation details
- Address both functional and non-functional requirements
- Consider the full system lifecycle

**Completeness:**
- Cover all aspects mentioned in the requirements
- Don't skip difficult or ambiguous areas
- Flag areas that need clarification

**Output:**
- Write the plan in clear, professional language
- Use markdown formatting
- Aim for comprehensive coverage while remaining concise
