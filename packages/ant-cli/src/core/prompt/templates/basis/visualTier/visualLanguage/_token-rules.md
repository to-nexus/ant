## Visual Language Token Rules

Constraint: All primary-emphasis elements MUST use the provided primary token.
Constraint: Do NOT invent additional brand colors outside the provided palette.
Constraint: Do NOT use system fonts or fonts requiring separate installation.
Constraint: All specified fonts MUST be loaded from Google Fonts CDN.
Constraint: Tokens are specifications, not suggestions. Use exact values.
Constraint: If a token is absent for a mode, that mode is not supported.
