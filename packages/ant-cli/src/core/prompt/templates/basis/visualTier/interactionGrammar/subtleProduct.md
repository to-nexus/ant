## Interaction Grammar: Subtle Product

Use subtle product-grade interaction.

**Motion**: Short transitions (150-200ms). Ease-out only. No bounce, no spring.
**Hover**: Restrained — slight background shift, subtle shadow elevation, or opacity change.
**Focus**: Visible focus ring with brand-appropriate color.
**Active**: Clear press feedback (scale down slightly or darken).
**Loading**: Skeleton screens for content areas. Spinner for actions.
**Empty**: Structured empty state with brief message and optional CTA.
**Error**: Inline error messages with error color. Toast for non-blocking errors.

Constraint: Motion should support clarity, not attract attention.
Constraint: Every interactive element must handle hover, focus, active states.
