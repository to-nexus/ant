## Surface System: Bordered Soft

Use softly bordered surfaces with clear panel boundaries.

**Panel treatment**: Subtle border + restrained shadow. Structured but not harsh.
**Depth**: Controlled — border is primary separator, shadow is supplementary.
**Borders**: Thin, low-contrast borders. Not heavy outlines.
**Grouping**: Explicit panel boundaries create clear visual groups.

Constraint: Prefer controlled separation over heavy shadow.
Constraint: Do NOT use borderless floating cards (every panel should have a visible boundary).
