## Interaction Grammar: Restrained

Use restrained interaction behavior.

**Motion**: Minimal. Avoid expressive animation. Transitions should be near-instant.
**Hover**: Subtle background shift only. No scale, no shadow change.
**Focus**: Clear, visible focus ring. Accessibility-first.
**Active**: Immediate visual feedback (background darken or opacity change).
**Loading**: Simple spinner or skeleton. No animated illustrations.
**Empty**: Plain text message. No decorative empty states.
**Error**: Clear error color + message. No animated error states.

Constraint: Avoid expressive animation. Utility-first transitions.
