## Surface System: Soft

Use soft surfaces with gentle separation.

**Panel treatment**: Light elevation via subtle shadow. Smooth visual transitions.
**Depth**: Gentle — perceptible but not dramatic.
**Borders**: Prefer soft shadow over hard border. Borders only when shadow is insufficient.
**Readability**: Low visual harshness. Surfaces should feel smooth.

Constraint: Keep the UI smooth and polished without becoming decorative.
Constraint: Do NOT use heavy shadows (max 1-2 levels of subtle elevation).
