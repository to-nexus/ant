## Component Semantics: Content Preview

Bias components toward content preview patterns.

**Primary components**: Preview cards, metadata summaries, content snippets, entry points.
**Secondary components**: Filter bars, sort controls, pagination.
**Card semantics**: A card is a content entry point. Show title, metadata, preview snippet.
**List semantics**: Lists are browsable collections with consistent preview quality.

Constraint: Prefer preview cards with metadata-aware summaries over abstract panels.
Constraint: Do NOT show content without metadata (date, type, status, author).
