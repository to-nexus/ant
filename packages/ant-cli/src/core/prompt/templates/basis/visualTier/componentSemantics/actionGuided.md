## Component Semantics: Action Guided

Bias components toward action-guided structures.

**Primary components**: Action cards, progress trackers, step indicators, CTA sections.
**Secondary components**: Context panels, informational sidebars.
**Card semantics**: A card represents an actionable item. Include explicit next-step or CTA.
**Section semantics**: Sections represent stages or phases of a workflow.

Constraint: Prefer actionable cards with explicit next steps over passive display.
Constraint: Do NOT create display-only layouts. Every section should guide toward an action.
