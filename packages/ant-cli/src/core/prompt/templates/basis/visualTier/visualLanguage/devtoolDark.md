## Visual Language: Developer Tool

Use a developer-tool visual language.

**Tone**: Utility-focused, dense, technical, productive.
**Typography**: Monospace-friendly, functional sizing, sharp grouping.
**Contrast**: High — dark backgrounds with clear foreground differentiation.
**Radius**: Minimal — sharp edges, functional grouping.
**Color posture**: Dark-first palette. Functional color coding (success/warning/error). Minimal decorative color.

Constraint: Favor productivity and technical clarity.
Constraint: Do NOT add decorative styling. Minimize whitespace waste.
