## Visual Hierarchy: Controlled Focus

Use controlled visual hierarchy with one clear focal area per screen.

**Primary**: One section or element receives primary visual emphasis per viewport.
**Secondary**: Supporting content has reduced visual weight (smaller text, muted color, less padding).
**Tertiary**: Navigation, metadata, and chrome are visually subordinate.

Constraint: Do NOT allow multiple competing primary elements on the same screen.
Constraint: Do NOT give equal visual weight to all sections. One must lead.
Constraint: Emphasis is achieved through size, contrast, and spacing — not through color alone.
