## Spatial System: Compact 8pt

Use a compact spatial system with tight but consistent spacing.

**Base unit**: 4px. Scale: 4, 8, 12, 16, 24, 32.
**Density**: High. Reduced padding, tighter grouping.
**Section gaps**: Small (16-24px between sections).
**Card/panel padding**: Compact (8-12px internal padding).
**Scanning**: Optimized for fast scanning of dense information.

Constraint: Preserve legibility while prioritizing information density.
Constraint: Do NOT use spacing values outside the 4px-based scale.
Constraint: Every spacing value must be a multiple of 4.
