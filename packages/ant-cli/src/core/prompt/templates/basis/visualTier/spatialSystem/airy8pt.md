## Spatial System: Airy 8pt

Use an airy spatial system with generous whitespace.

**Base unit**: 8px. Scale: 8, 16, 24, 32, 48, 64.
**Density**: Low. Generous whitespace, calm rhythm.
**Section gaps**: Large (32-48px between sections).
**Card/panel padding**: Generous (24-32px internal padding).
**Pace**: Slower reading pace. Breathing room for emphasis.

Constraint: Preserve structure while giving sections room to breathe.
Constraint: Do NOT compress spacing to fit more content. Let the layout be spacious.
Constraint: Every spacing value must follow the scale.
