## Visual Hierarchy: Quiet Layered

Use quiet layered hierarchy with restrained contrast and spacing-led grouping.

**Hierarchy method**: Spacing and positioning create importance, not strong color or scale.
**Primary**: Slightly more padding and vertical position (top) indicate importance.
**Secondary**: Normal spacing and position.
**Tertiary**: Reduced spacing, smaller type, or indentation.

Constraint: Let structure and rhythm create importance before strong color.
Constraint: Do NOT use aggressive size differences or strong color contrast for hierarchy.
Constraint: The hierarchy should feel calm even when content is complex.
