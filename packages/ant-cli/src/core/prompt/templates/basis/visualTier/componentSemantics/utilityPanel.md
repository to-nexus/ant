## Component Semantics: Utility Panel

Bias components toward utility panels and control groups.

**Primary components**: Control groups, parameter panels, setting rows, toggle sections.
**Secondary components**: Help text, status indicators, save/cancel actions.
**Panel semantics**: A panel is an explicit control group. Label its purpose.
**Row semantics**: Settings are organized in labeled rows with controls on the right.

Constraint: Prefer explicit panel roles and grouped controls over decorative card layouts.
Constraint: Do NOT use card-heavy decorative composition for utility interfaces.
