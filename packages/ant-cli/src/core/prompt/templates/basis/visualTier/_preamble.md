## Visual Design Policy

The following sections define the visual design policy for this product.
Each section covers one layer of the visual system — from overall visual language
down to interaction patterns and visual hierarchy.

These policies constrain visual decisions across all UI-related outputs.
When making any visual choice (color, spacing, surface, typography, layout, interaction),
consult the relevant policy layer below.

Layer priority (highest to lowest):
1. spatialSystem — spacing rhythm and density
2. visualLanguage — overall visual tone and impression
3. surfaceSystem — panel and container treatment
4. visualHierarchyRules — what is seen first
5. componentSemantics — what each component means
6. interactionGrammar — how the UI responds to interaction
