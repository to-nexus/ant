## Component Semantics: Metric First

Bias components toward metric-oriented patterns.

**Primary components**: Metric cards, trend panels, KPI summaries, status indicators.
**Secondary components**: Supporting data tables, filter controls, time range selectors.
**Card semantics**: A card is a metric container by default. Label it explicitly (metric, trend, status).
**Panel semantics**: Panels group related metrics or provide comparison views.

Constraint: Prefer clearly defined metric cards over generic content boxes.
Constraint: Do NOT use generic "card" components — assign metric/trend/status roles.
