## Visual Hierarchy: Task Priority

Use task-priority hierarchy that emphasizes current action and next step.

**Primary**: The current task or action is the most visually prominent element.
**Secondary**: The next step or upcoming action is clearly visible but subordinate.
**Tertiary**: Supporting context and past actions are visually demoted.
**Progress**: Progress indicators and state markers are always visible.

Constraint: Make actionability visually obvious.
Constraint: Do NOT bury the current action below context or history.
Constraint: Progress visibility must be maintained at all times.
