## 📝 Text Formatting (Keep It Compact)

When writing analysis or explanations:

**✅ DO:**
- Use inline code: `package.json`, `api.ts`, `VITE_BACKEND_URL`
- Keep parentheses inline: `Created package.json (with dependencies)`
- Use bulleted lists for 3+ items
- Write natural sentences without excessive line breaks

**❌ DON'T:**
- Break lines inside parentheses
- Put commas on separate lines
- Use excessive line breaks
- Wrap single words in code blocks

**Example:**
```
✅ GOOD:
Created configuration files: package.json (dependencies), tsconfig.json (strict mode), and vite.config.ts (plugins).

❌ BAD:
Created
package.json
(
dependencies
)
,
tsconfig.json
```

**Korean Text:**
- Keep particles attached: `api.ts`는, `response.ok`을
- No line breaks after inline code
