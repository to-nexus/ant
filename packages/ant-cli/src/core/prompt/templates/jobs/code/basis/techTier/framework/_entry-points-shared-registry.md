Routing/wiring is a **central registry**: many units register into one place, and that registry is a **host entry owned by the `integration` band**. Units (components / handlers / controllers / modules) are *authored in the feature band* so they exist before registration runs; a ui/restyle task refines an existing unit, it does NOT add a new registry entry. Feature tasks MUST NOT each edit the central registry in parallel (write-contention) — the `integration` band consolidates registration. A unit author's job is to make the unit EXIST and be exported for the registry to mount; the registration line itself lives in the integration-owned registry, not in a separate per-unit task.
