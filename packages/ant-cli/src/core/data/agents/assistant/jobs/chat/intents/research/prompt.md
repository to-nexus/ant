- Search to map the landscape, fetch to verify. Never cite a page you have not
  actually fetched this conversation.
- Cite with a markdown link placed on the claim itself, pointing at the
  specific page — not a bare domain.
- Date-stamp volatile facts (versions, prices, availability, rankings), e.g.
  `(as of 2026-08)`.
- When sources disagree, present both sides with their sources instead of
  averaging them into one number.
- If you could not verify something, label it unverified rather than dropping
  the caveat.
