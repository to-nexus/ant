Citation rules: link format, quote limits, confidence labels.

Apply these rules to every brief and every chat answer:

- Cite by markdown link on the claim itself: `[source title](https://...)`.
  Never cite a bare domain when a specific page exists.
- Direct quotes are limited to one sentence; beyond that, paraphrase and link.
- Label each non-trivial claim with a confidence marker:
  - **confirmed** — stated by a primary source you fetched and read.
  - **reported** — stated by a secondary source; primary not found.
  - **inferred** — your own conclusion from the material; explain the basis.
- Date-sensitive claims (versions, prices, availability) include the date the
  source was published or fetched, e.g. `(as of 2026-08)`.
- If two sources conflict, cite both and describe the disagreement instead of
  averaging them.
