# 팀 협업 프로젝트 관리 서비스

## 핵심 기능
- 프로젝트 생성 및 멤버 초대 (역할: Owner, Admin, Member)
- 칸반 보드 (드래그 앤 드롭, 컬럼 커스터마이징)
- 실시간 댓글 및 멘션 (WebSocket)
- 대시보드 (진행률, 마감 임박 태스크, 팀원별 워크로드)

## 기술 스택
- Frontend: React, TypeScript, Tailwind CSS
- Backend: Node.js, Express, PostgreSQL
- 실시간: WebSocket (Socket.io)
- 인증: OAuth 2.0 (Google, GitHub)
